# 🎲 Aura Ludo Pro Simulator

A modern, immersive, browser-based Ludo game simulator engineered with **React 19**, **Vite**, and high-performance **WebAssembly (C++)** game logic with a pure JavaScript fallback.

See the full project details, architecture, and documentation in [`Ludo-simulator-/README.md`](./Ludo-simulator-/README.md).

## 🚀 Vercel Deployment

When deploying to [Vercel](https://vercel.com):
- **Root Directory**: `Ludo-simulator-`
- **Framework Preset**: `Vite`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
